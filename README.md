# Frame — video editor & photographer portfolio

Plain HTML/CSS/JS with GSAP (motion), ScrollTrigger (scroll animation) and Lenis (smooth scroll). No build step.

## Change the content
Edit `content.js` — name, email, films, photos, services, clients, social links.
Put your own files in `media/`:
- films: a short muted `.mp4` (5–10 s, 1280px wide) + a `.jpg` poster per project
- `reel.mp4`: your showreel (opens full screen when the hero video is clicked)
- photos: `.jpg`, about 1600px on the long side

## Run it locally
Any static server works, e.g. `npx serve .` inside this folder.

## Put it online
Drag this folder onto https://app.netlify.com/drop (or Vercel / GitHub Pages).
